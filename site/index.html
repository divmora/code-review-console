How it works

Webhook in, review out

The console never calls a model itself. Each review runs the codereview CLI with short-lived credentials, so the engine is the same open-source bot you can run by hand.

Webhook

GitHub, GitLab (system, group or project hooks) and Bitbucket send events. Signatures are verified per host.

Decide and queue

Skips closed PRs, drafts and repositories that aren't enabled; can wait until the bot is a requested reviewer. One review per PR at a time.

Run the bot

A local process, a locked-down Docker container, or a Kubernetes Job with its own Secret that is deleted after the run.

Review and history

Inline comments, a summary and scores land on the PR. Results, tokens and timings are kept for the admin panel and dashboard.

Features

Run code review as a service

Everything around the review: who gets reviewed, when, with which settings, and what it cost. Features marked paid need a license key.

GitHub, GitLab, Bitbucket

github.com and GitHub Enterprise (token or GitHub App), gitlab.com and self-managed GitLab with signed webhooks, and Bitbucket Cloud. Hosts are managed in the panel, with tokens encrypted at rest.

Admin panel

Turn repositories on or off as they appear, set review profile, model and instructions per repository, browse every review and webhook, and re-run any review.

Chat commands

Mention the bot on a PR: review, full review, ask, help. The mention name follows the bot account's token user.

Rules paid

Settings for a whole host, a group (subgroups included) or a name pattern. The most specific level wins, per setting.

Team learnings paid

Reply to the bot with a team decision and it is remembered for future reviews of that repository or group. @bot remember saves one directly.

Docker & Kubernetes paid

Each review isolated in a container or a Job: read-only root, no capabilities, resource limits, and workload identity for cloud models.

Metrics & budgets paid

Daily and monthly rollups, token use, and daily token budgets for all repositories or per repository. History beyond 30 days.

Branch-sync skip paid

Merge requests that only bring a default branch into another one are skipped, so a 400-file sync doesn't cost a review.

SSO & audit paid

Admin sign-in through any OIDC provider, by email (free) or by domain or group, and an audit log of every admin change.

Get started

Up in a few minutes with Docker Compose

Starts the console and PostgreSQL. Add your model and code host in console.yaml, point a webhook at the console, and turn on a repository in the admin panel.

Terminal 
# get the console and its example config
git clone https://github.com/divmora/code-review-console.git
cd code-review-console
cp examples/console.yaml console.yaml      # models, code hosts, admin sign-in

docker compose up -d --build               # console + PostgreSQL on :8080
docker compose exec console code-review-console check-config --config /etc/console/console.yaml

# paid features: paste a license key under License in the admin panel,
# or set CODEREVIEW_CONSOLE_LICENSE
